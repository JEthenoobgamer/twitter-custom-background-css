# twitter-custom-background-css
Some simple CSS template stylesheets to customize you twitter background using the Control Panel for Twitter extension

Requires the extension Control Panel for Twitter by Jonny Buchanan, which you can get here:
https://soitis.dev/control-panel-for-twitter

How to use?
1)Install and enable the extension.
2)Open the extension's settings and scroll down to the "Experiments" tab.
3)Copy and paste the css on "Custom CSS", then click "Save and apply".

Then, have fun with it, you can use different solid colors, gradients, images, whatever CSS let's you use as a background for a container.
These are just some templates so that you don't need to look for what to change by yourself if you only want to change the background. But remember to experiment with it and investigate as much as you'd like, you can probably change anything you want from the website with that extension.

Also these are the variables I found to be used for the background, some might change in the future (I don't know how twitter works with that), in that case if it breaks for you you can just look for them using the inspector (f12) and change them in the CSS. There might be better ways to do this tho.
